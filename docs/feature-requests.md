# Фичи на потом

Не входят в первую версию. Решения по текущей версии — в [QnA.md](QnA.md).

## Карта и обзор

- Источники света, которые мастер ставит на карту. Источники света из инвентаря работают уже в первой версии.
- Поправки обзора на освещение.
- Настройка: сбрасывать ли состояние карты (туман, NPC, рисунки), когда мастер снова выбирает её в игре.
- Пересмотреть, что происходит с объектами при изменении сетки (в первой версии привязанные к сетке объекты остаются в своих ячейках).

## NPC

- Размеры NPC больше 1×1.
- Хиты, КД и другие боевые параметры NPC.
- Полный каталог Too Many Tokens (около 16 000 токенов), если поместится.
- Загрузка мастером своего аватара NPC.

## Игра

- Панель логов бросков на телефоне (в первой версии на телефоне её нет).
- Несколько сохранений игры на кампанию и загрузка сохранения без пересоздания кампании и без экспорта архива (в первой версии одно сохранение).

## Инвентарь

- Настройка видов валют (например, вернуть электрум).
- Внутриигровые предметы со своими карточками, которые создаёт мастер (из описания).

## Интерфейс

- Другие языки интерфейса.
- Опции в меню пользователя редактора (из описания).
- Автосохранение каждого действия в редакторе, как в Figma, если в первой версии будет только ручное сохранение (из описания).

## Печать

- Шаблон для печати листа персонажа и листа спутника: кнопка «Печать» открывает PDF-версию листа (из описания). Какой будет шаблон — решим позже.

## Релиз

- Публичная бесплатная версия: только ресурсы с открытой лицензией, контент правил из закрытых источников убрать или отделить.
